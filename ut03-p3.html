HANA · Hero con superposición y posicionamiento

position: absolute/sticky, clamp(), object-fit, overlays con ::before

1Enunciado

El restaurante HANA necesita una sección hero de impacto para su página de inicio. Se trata de una imagen grande a pantalla completa con un overlay de degradado oscuro (creado con ::before), un badge de categoría flotante en la esquina superior derecha (con position: absolute), un bloque de texto centrado sobre la imagen, y un encabezado de sección sticky que se pega al tope al hacer scroll para identificar los platos del menú principal.

Además, el título principal del hero usa clamp() para ser fluido entre móvil y escritorio, y la imagen de fondo usa object-fit: cover para recortar bien en todas las pantallas.

3Conceptos clave

El truco del hero con superposición: hay tres capas apiladas con z-index.

📐 Esquema de capas
/* Capa 1 — imagen (z-index más bajo) */
.hero-img {
  position: absolute;  /* sacada del flujo */
  inset: 0;            /* top:0 right:0 bottom:0 left:0 */
  z-index: 0;
  width: 100%; height: 100%;
  object-fit: cover;    /* recorta sin deformar */
}

/* Capa 2 — overlay con ::before (z-index 1) */
.hero::before {
  content: "";
  position: absolute; inset: 0;
  z-index: 1;
  background: linear-gradient(to bottom, transparent, rgba(0,0,0,.75));
}

/* Capa 3 — texto (z-index 2, el más alto) */
.hero-content {
  position: absolute; inset: 0;
  z-index: 2;
  display: flex; flex-direction: column;
  align-items: center; justify-content: center;
}

/* OJO: .hero necesita position:relative + min-height
   para que sus hijos absolute tengan dónde anclarse */
.hero {
  position: relative;
  min-height: 92vh;
}

clamp() — tipografía fluida:

📐 Sintaxis de clamp()
/* clamp(mínimo, preferido, máximo) */
font-size: clamp(48px, 10vw, 120px);
/*
   En móvil 375px: 10vw = 37.5px → aplica el mínimo → 48px
   En tablet 768px: 10vw = 76.8px → usa 76.8px (entre min y max)
   En desktop 1200px: 10vw = 120px → aplica el máximo → 120px
*/

/* Sin clamp(), necesitarías tres media queries para esto.
   Con clamp() es un solo valor que funciona en todos los tamaños. */

position: sticky — cómo funciona:

📐 Sticky vs fixed
/* STICKY: ocupa su espacio en el flujo, pero
   "se pega" al borde cuando llegas a él al scrollear */
.titulo-seccion {
  position: sticky;
  top: 0;   /* umbral: se pega cuando llega a 0px del tope */
  z-index: 10;
}

/* CLAVE: para que sticky funcione, el padre NO puede tener
   overflow:hidden ni overflow:auto    */

/* FIXED: siempre anclado a la ventana, NO ocupa espacio
   en el flujo (como la nav de P2). Sticky es mejor para
   encabezados de sección dentro de una página larga. */
ℹ️
¿Por qué el héroe necesita overflow: hidden? La imagen tiene position: absolute con inset: 0, por lo que respeta los límites del contenedor. Pero si usáramos height: 92vh en lugar de min-height, la imagen podría desbordarse en algunos navegadores. overflow: hidden garantiza que nada se salga del recuadro del hero.
✅
object-fit: cover vs contain cover → recorta para rellenar todo el espacio (como "background-size: cover"). contain → ajusta toda la imagen dentro del espacio (puede dejar huecos). Para un hero siempre usamos cover.

4Guía paso a paso

  1. Convierte .hero en contenedor de posicionamiento: añade position: relative y min-height: 92vh. Sin esto, los hijos con position: absolute se anclan al elemento posicionado más cercano, que por defecto sería <body>.
  2. Ancla la imagen al héroe: dale a .hero-img los valores position: absolute; inset: 0; width: 100%; height: 100%; object-fit: cover. Verás que la imagen llena completamente el hero.
  3. Crea el overlay con ::before: el pseudo-elemento .hero::before necesita content: "" (obligatorio para que aparezca), position: absolute; inset: 0 y un background con linear-gradient. Ponle z-index: 1 para que quede entre la imagen y el texto.
  4. Coloca el badge en la esquina: .hero-badge necesita position: absolute; top: 20px; right: 20px y z-index: 3 (encima del overlay y del texto).
  5. Centra el bloque de texto: .hero-content va con position: absolute; inset: 0 más display: flex; flex-direction: column; align-items: center; justify-content: center; z-index: 2. Al poner inset: 0, el contenedor cubre todo el hero y flex centra su contenido.
  6. Tipografía fluida con clamp(): para .hero-titulo usa font-size: clamp(48px, 10vw, 120px). Para .hero-subtitulo usa font-size: clamp(16px, 2.5vw, 24px). Redimensiona la ventana y observa cómo el título escala sin saltos.
  7. Sticky para el título del menú: añade position: sticky; top: 0; z-index: 10 a .menu-sticky-titulo. Haz scroll en la página y comprueba que se pega al tope cuando llegas a él.
  8. Imágenes de las cards con object-fit: en .menu-card-img pon height: 200px; object-fit: cover. Sin esto, las imágenes se deforman según su tamaño original.
  9. Media queries: en tablet (min-width: 48em), amplía el padding del sticky. En desktop (min-width: 64em), limita el grid a 3 columnas fijas.
⚠️
Error frecuente: sticky no funciona Si position: sticky no parece hacer nada, revisa: (1) ¿Tiene top definido? Es obligatorio para que sticky sepa cuándo pegarse. (2) ¿El padre o algún ancestro tiene overflow: hidden o overflow: auto? Eso rompe sticky. El overflow en .hero no afecta porque el sticky está fuera del hero.
