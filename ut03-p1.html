HANA — Flexbox avanzado: la card de plato responsive

Proyecto HANA · Restaurante japonés · Duración estimada: 90 min

1Contexto

En UT02 construiste la card de un plato de HANA. Ahora tiene que funcionar en móvil, tablet y escritorio. Para eso necesitas el modelo completo de Flexbox: no solo justify-content y align-items, sino entender cómo los hijos se distribuyen el espacio disponible.

El resultado final: en móvil la imagen y el texto se apilan; en tablet se colocan en fila con la imagen a la izquierda ocupando un tercio fijo; en escritorio el texto puede crecer libremente y la imagen nunca se deforma.

2Conceptos que se trabajan

flex-grow flex-shrink flex-basis shorthand flex order align-self mobile-first @media min-width flex-direction
ℹ️
Lo que ya sabes de UT02 display: flex, justify-content, align-items, gap, flex-direction, flex-wrap. Esta práctica construye encima de eso.

3Resultado esperado

Así debe verse la card en cada breakpoint:

📱 Móvil — < 480px
📐 Tablet — ≥ 768px
🖥 Escritorio — ≥ 1024px

5Guía paso a paso

  1. TODO 1 — La card como flex container en móvil: añade display: flex; flex-direction: column a .card-plato. En móvil los hijos se apilan verticalmente.
  2. TODO 2 y 3 — card-cuerpo con footer al fondo: .card-cuerpo necesita display: flex; flex-direction: column; flex: 1. Luego en .card-footer añade margin-top: auto. Esto empuja el footer hacia abajo independientemente de cuánto texto haya.
  3. TODO 4 — Ocultar .card-meta en móvil: añade display: none a .card-meta. Los metadatos no tienen espacio en móvil.
  4. TODO 5, 6 — Fila horizontal en tablet: dentro de @media (min-width: 768px), cambia .card-plato a flex-direction: row y añade align-items: stretch para que todos los hijos alcancen la misma altura.
  5. TODO 7, 8 — Imagen de tamaño fijo: a .card-imagen dale flex: 0 0 200px: no crece, no encoge, siempre mide 200px. A la imagen height: 100%; object-fit: cover para que rellene toda la altura.
  6. TODO 9 — Texto que crece: a .card-cuerpo dale flex: 1. Se lleva todo el espacio libre que no usan la imagen ni la columna meta.
  7. TODO 10, 11 — Mostrar columna meta en tablet: cambia .card-meta a display: flex; flex: 0 0 120px; border-left: 1px solid #eee. Aparece como columna lateral derecha.
  8. TODO 12, 13 — Ajustar proporciones en escritorio: aumenta los flex-basis: imagen a 240px, meta a 160px. El cuerpo (flex: 1) absorbe automáticamente el espacio restante.

6Solución comentada

Solo los bloques que cambian. Las líneas en amarillo son los TODOs resueltos.

✅ CSS style.css — solución
.card-plato {
  background: white; border-radius: 12px;
  overflow: hidden; box-shadow: 0 2px 12px rgba(0,0,0,.08);
  display: flex;           /* TODO 1 */
  flex-direction: column;
}
.card-cuerpo {
  padding: 20px;
  display: flex;           /* TODO 2 */
  flex-direction: column;
  flex: 1;
}
.card-footer {
  display: flex; justify-content: space-between; align-items: center;
  margin-top: auto;        /* TODO 3: empuja al fondo */
}
.card-meta {
  display: flex; flex-direction: column; gap: 6px;
  padding: 16px; background: #fafafa; border-top: 1px solid #eee;
  display: none;           /* TODO 4: ocultar en móvil */
}

@media (min-width: 768px) {
  .card-plato {
    flex-direction: row;    /* TODO 5 */
    align-items: stretch;  /* TODO 6 */
  }
  .card-imagen {
    flex: 0 0 200px;        /* TODO 7: fijo, ni crece ni encoge */
  }
  .card-imagen img {
    height: 100%;           /* TODO 8 */
  }
  .card-cuerpo {
    flex: 1;                /* TODO 9: espacio libre */
  }
  .card-meta {
    display: flex;           /* TODO 10 */
    flex: 0 0 120px;
    border-left: 1px solid #eee; /* TODO 11 */
    border-top: none;
  }
}

@media (min-width: 1024px) {
  .card-imagen {
    flex: 0 0 240px;        /* TODO 12 */
  }
  .card-meta {
    flex: 0 0 160px;        /* TODO 13 */
  }
  .card-cuerpo { padding: 28px; }
}
💡
¿Por qué flex: 0 0 200px y no width: 200px? Con width, Flexbox puede encoger el elemento por debajo de ese valor si no hay espacio. Con flex: 0 0 200px (shrink=0) garantizas que nunca encogerá. Para columnas fijas en layouts flex, siempre usa la shorthand.
💡
margin-top: auto en un flex child Dentro de un flex container en columna, margin-top: auto consume todo el espacio libre disponible por encima, empujando el elemento al fondo. Es la técnica más limpia para "footer pegado al fondo de una card".
