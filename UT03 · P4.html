HANA — CSS Grid avanzado: la página de menú

grid-template-areas · auto-fill/auto-fit · minmax() · líneas numéricas · grid implícito

1Contexto

En P3 colocaste los elementos del hero con position: absolute. Ahora toca maquetar la página entera del menú de HANA usando CSS Grid como herramienta principal. No se trata solo de crear una rejilla de tarjetas: aprenderás a nombrar áreas, a que el grid se adapte automáticamente al espacio disponible (auto-fill), y a colocar un elemento concreto en coordenadas exactas usando líneas numéricas.

El reto añadido: una tarjeta "especial del chef" que siempre ocupa dos columnas, esté donde esté en el flujo del grid.

2Conceptos que se trabajan

grid-template-areas grid-area auto-fill vs auto-fit minmax() grid-column / grid-row span grid implícito repeat() gap mobile-first
ℹ️
Grid vs Flexbox — cuándo usar cada uno Flexbox es unidimensional: organiza elementos en una fila o en una columna. Grid es bidimensional: controla filas y columnas al mismo tiempo. Para layouts de página completa, cuadrículas de tarjetas o cualquier diseño con dos ejes, Grid es la herramienta correcta.

3Resultado esperado

Layout de la página de menú en cada breakpoint. La tarjeta marcada con ★ es el plato especial del chef y siempre ocupa dos columnas:

📱 Móvil — 1 col
📐 Tablet — 2 col auto-fill

ℹ️
auto-fill vs auto-fit Ambos crean columnas automáticamente. La diferencia está cuando hay pocos elementos: auto-fill mantiene las columnas vacías (el grid mantiene su estructura), auto-fit las colapsa y los elementos existentes crecen para llenar el espacio. Para la mayoría de grids de tarjetas, auto-fill con minmax es la opción correcta.

5Conceptos clave

grid-template-areas — nombrar regiones del layout

📐 grid-template-areas
/* En el container: dibuja el layout con nombres */
.pagina {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header  header"   /* fila 1: header ocupa 2 cols */
    "sidebar contenido" /* fila 2: sidebar + contenido */
    "footer  footer";   /* fila 3: footer ocupa 2 cols */
}

/* En cada hijo: asígnalo a un área */
.site-header { grid-area: header; }
.sidebar     { grid-area: sidebar; }
.contenido   { grid-area: contenido; }
.site-footer { grid-area: footer; }

auto-fill + minmax() — columnas que se adaptan solas

📐 auto-fill con minmax
/* Las columnas se crean automáticamente:
   - Mínimo 240px cada una
   - Máximo: 1fr (reparten el espacio sobrante)
   - En móvil cabe 1 columna, en tablet 2, en desktop 3... */
.menu-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(min(100%, 240px), 1fr));
  gap: 16px;
}

/* min(100%, 240px): si el contenedor mide menos de 240px
   (ej. móvil estrecho), el mínimo se reduce para evitar
   desbordamiento horizontal. Siempre úsala con auto-fill. */

grid-column span — elemento que ocupa varias columnas

📐 span y líneas numéricas
/* Forma 1: span (relativa) — ocupa N columnas desde donde esté */
.especial { grid-column: span 2; }

/* Forma 2: líneas numéricas (absoluta) — de línea X a línea Y */
.especial { grid-column: 1 / 3; }   /* de col 1 a col 3 (ocupa 2) */
.especial { grid-column: 2 / 4; }   /* de col 2 a col 4 (ocupa 2) */
.especial { grid-column: 1 / -1; }  /* de la primera a la última */

/* grid-row funciona igual pero para filas */
.especial { grid-row: span 2; }     /* ocupa 2 filas de altura */

/* Las líneas son los bordes de las celdas:
   col 1  col 2  col 3
   |──────|──────|──────|
   1      2      3      4 (líneas numéricas)  */
💡
Grid implícito — las filas que crea el navegador Cuando defines grid-template-columns pero no grid-template-rows, el navegador crea filas automáticamente para los elementos que no caben en las columnas definidas. Eso es el grid implícito. Puedes controlar su altura con grid-auto-rows: minmax(200px, auto).

💡
¿Por qué repeat(auto-fill, minmax(min(100%, 240px), 1fr)) y no simplemente minmax(240px, 1fr)? Sin el min(100%, 240px), si el contenedor mide menos de 240px (teléfono muy estrecho o elemento anidado), el grid intentaría crear una columna de 240px y causaría scroll horizontal. min(100%, 240px) dice "lo que sea menor: el 100% del contenedor o 240px". Es la forma robusta de usar auto-fill.
💡
grid-template-areas + grid-area: ventajas El layout queda visual en el CSS — puedes leer la cuadrícula de texto y ver el diseño. Cambiar el layout en un breakpoint es tan simple como reescribir la cadena de áreas, sin tocar los hijos. Es la técnica más legible para layouts de página completa.
